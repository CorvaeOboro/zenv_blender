Remap texture paths in materials

Scans all materials in the blend file, finds image texture nodes whose filepath contains a user-specified old path prefix, and replaces that prefix with a new path while optionally changing the file extension. Only remaps if the target file exists on disk. Forces image updates and area redraws after remapping.

MAT Remap Textures - A Blender addon for texture path remapping.
remap texture paths in materials, switch between texture sets.
