rename material by texture name

Rename and merge materials based on their base color texture names

Scans selected mesh objects for materials with a Principled BSDF whose Base Color input is connected to an Image Texture node. Extracts the texture name (stripping optional prefix/suffix) to derive a base name. Optionally renames materials to match the texture base name (with an optional suffix added). Optionally merges materials that share the same texture base name by replacing all references with the first material and removing the duplicates.

MAT Rename Material by Texture - A Blender addon for renaming and merging materials.
1. Scans selected mesh objects for materials with base color textures.
2. Extracts the texture base name (stripping configurable prefix/suffix).
3. Renames materials to match the texture base name (with optional suffix).
4. Optionally merges materials that share the same texture base name.
Only selected objects are scanned; merge replaces references on all objects.
